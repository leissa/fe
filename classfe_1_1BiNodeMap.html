Detailed Description

template<class L, class R, class LHash = ankerl::unordered_dense::hash<L>, class LEq = std::equal_to<L>, class RHash = ankerl::unordered_dense::hash<R>, class REq = std::equal_to<R>>
class fe::BiNodeMap< L, R, LHash, LEq, RHash, REq >

A bijection between L and R that stores every pair once, in an ankerl::unordered_dense::segmented_map.

The right side is a set of pointers to those pairs, hashed and compared by their R. An insert never moves a pair, and neither does moving the BiNodeMap itself. An erase, however, moves the last pair into the freed slot, as it does in any ankerl::unordered_dense map. Its interface is that of BiMap, except that right() has no map to yield; find_right() takes its place.
