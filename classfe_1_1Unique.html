Detailed Description

template<class Set, template< class > class C>
class fe::Unique< Set, C >

A worklist that pushes each element at most once.

Set remembers what has already been pushed and may be a reference to share it with the caller. Use it through the UniqueQueue/UniqueStack aliases.
