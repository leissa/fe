Detailed Description

template<class L, class R, class LHash = ankerl::unordered_dense::hash<L>, class LEq = std::equal_to<L>, class RHash = ankerl::unordered_dense::hash<R>, class REq = std::equal_to<R>>
class fe::BiMap< L, R, LHash, LEq, RHash, REq >

A bijection between L and R, kept as one ankerl::unordered_dense::map per direction.

Look up through left() and right(); a transparent hasher and equality enable heterogeneous lookup there as well. Iterating a BiMap yields its std::pair<L, R>s in left() order.

Note
Every pair is stored once per direction, so keep L and R cheap to copy - a Sym or a pointer, say. Otherwise, or if you need a pair's address to survive an insert, use BiNodeMap.
